7. Familia de Programación No Lineal (Tu frontera final) Donde la función objetivo o las restricciones ya no son funciones estrictamente lineales.

* Búsqueda de la sección áurea: Para optimizar funciones de una sola variable reduciendo el intervalo de incertidumbre.

* Método del ascenso escalonado: Para la maximización o minimización no restringida con varias variables aplicando gradientes.

* Multiplicadores de Lagrange: Para optimización sujeta exclusivamente a restricciones de igualdad.

* Condiciones de Kuhn-Tucker (K-T): Para evaluar la optimalidad en problemas que incluyen restricciones de desigualdad.

* Método de Wolfe: Aplica una fase modificada del Simplex para resolver programación cuadrática.

* Programación separable: Aproxima funciones no lineales dividiéndolas en tramos o funciones lineales por partes.

* Método de las direcciones factibles: Otra técnica basada en gradientes para avanzar hacia el óptimo respetando las restricciones no lineales.
