5. Familia de Programación Entera (Variables Discretas) Algoritmos para manejar problemas en donde las variables de decisión no pueden ser fracciones (tienen que ser números enteros o binarios).

* Método de ramificación y acotamiento (Branch and Bound): El algoritmo más común en la práctica para la programación entera pura o mixta.

* Métodos heurísticos del agente viajero: Como el vecino más cercano o la inserción más barata, para problemas de optimización combinatoria complejos.

* Método de enumeración implícita: Exclusivo para problemas donde las variables son binarias (0 o 1).

* Algoritmo del plano de corte: Introduce nuevas restricciones al modelo continuo para ir cortando las soluciones que dan resultados fraccionarios.
