4. Familia de Modelos de Redes Algoritmos que operan sobre estructuras de grafos (nodos y arcos) para problemas de flujo.

* Algoritmo de Dijkstra: Para encontrar la trayectoria más corta entre nodos.

* Método de Ford-Fulkerson: Para problemas de flujo máximo dentro de una red.

* Algoritmo del árbol de expansión mínima (MST): Un algoritmo ávido para conectar todos los nodos minimizando la distancia o costo.

* Métodos CPM y PERT: Para planificar la ruta crítica y gestionar los tiempos de proyectos complejos.

* Método simplex para redes: Algoritmo que generaliza la solución para problemas de flujo de red de costo mínimo.
