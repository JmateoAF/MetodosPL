6. Familia de Temas Avanzados de Programación Lineal Son algoritmos modificados para que las computadoras puedan procesar problemas gigantescos consumiendo menos memoria.

* Método simplex revisado y la forma producto de la inversa: Ejecuta el simplex manejando operaciones de matrices de manera altamente eficiente para el software.

* Generación de columnas: Para manejar problemas con demasiadas variables (como el problema de corte de material) sin tener que calcularlas todas a la vez.

* Algoritmo de descomposición de Dantzig-Wolfe: Divide un problema gigante en varios subproblemas más manejables que se coordinan por un programa maestro.

* Método simplex para variables acotadas superiormente: Resuelve problemas con límites máximos de forma rápida sin sumar restricciones extra al modelo.

* Método de Karmarkar: Un algoritmo moderno polinomial de punto interior para problemas a gran escala que rivaliza con el simplex.
